# Информационная система планирования междугородних грузовых перевозок

Учебная практика, РТУ МИРЭА, 2026.

**Тема:** Междугородние грузовые автомобильные перевозки,
**Автор:** Токмянин Родион Александрович, группа ИКБО-10-24

## Автоматизируемый бизнес-процесс

«Обработка заявки на междугороднюю перевозку груза и планирование рейса»:
от поступления заявки от грузоотправителя до передачи рейсового задания водителю.

## Стек

- Python 3.13 - процедурная реализация алгоритмов
- Java 25 + Spring Boot 4.0 (Maven) - объектно-ориентированная реализация, веб-приложение
- PostgreSQL 17 - база данных

## Структура репозитория

- `docs/` - описание предметной области и бизнес-процесса
- `db/` - SQL-скрипты базы данных
- `python/` - процедурная реализация (Python)
- `java/` - объектно-ориентированная реализация (Java, Spring Boot)
