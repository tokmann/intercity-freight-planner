# Планирование междугородних рейсов: процедурная версия

Программа автоматизирует операции бизнес-процесса «Обработка заявки на междугороднюю перевозку груза и планирование рейса». Она регистрирует входящие заявки, проверяет их комплектность, рассчитывает время в пути с учетом режима труда и отдыха водителя, подбирает автомобиль и водителя, считает стоимость по тарифной сетке и формирует рейсовое задание.

Реализация процедурная: только функции и стандартные структуры данных (`dict`, `list`, `tuple`, `set`), своих классов и глобальных изменяемых переменных нет.

## Требования и запуск

Нужен Python 3.13. Используется только стандартная библиотека, внешних зависимостей нет.

Из папки, где лежит `main.py`:

```
python main.py
```

По умолчанию данные читаются из `data/fleet.json` и `data/incoming.json`. Другие файлы можно указать параметрами:

```
python main.py --fleet data/fleet.json --incoming data/incoming.json
```

## Файлы

| Файл | Содержимое |
|---|---|
| `main.py` | запуск из командной строки и вывод результата |
| `planner.py` | операции процесса и алгоритмы |
| `storage.py` | загрузка JSON-файлов, преобразование дат |
| `data/fleet.json` | клиенты, типы кузова, допуски, автомобили, водители, допуски водителей, тарифы, журнал заявок, рейсы и назначения водителей |
| `data/incoming.json` | входящие заявки грузоотправителей |

Коллекции в `data/fleet.json` соответствуют сущностям логической модели данных: `clients` – Клиент, `body_types` – Тип кузова, `permits` – Допуск, `vehicles` – Автомобиль, `drivers` – Водитель, `driver_permits` – Допуск водителя, `tariffs` – Тариф, `requests` – Заявка, `trips` – Рейс, `trip_drivers` – Назначение водителя на рейс.

## Операции и функции

| Операция процесса | Функция |
|---|---|
| Зарегистрировать заявку | `register_request()` |
| Проверить комплектность заявки | `check_request()` |
| Рассчитать время в пути | `calc_travel_time()` |
| Подобрать автомобиль | `select_vehicle()` |
| Подобрать водителя | `select_driver()` |
| Рассчитать стоимость перевозки | `calc_cost()` |
| Сформировать рейсовое задание | `make_trip_task()` |

Функция `process_request()` проводит заявку по шагам процесса в том же порядке, что на BPMN-диаграмме.

```json
  "body_type_id": 1,

  "loading_address": "Москва, ул. Складская, 5",
  "unloading_address": "Казань, ул. Тэцевская, 4",

  "delivery_deadline": "2026-10-28T18:00",
  "cargo_mass_t": 18,

  "temperature_mode": "",

}
```
